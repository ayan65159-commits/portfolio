# Ayan Ali — Portfolio

My personal portfolio website.

**Live site:** https://ayan65159-commits.github.io/portfolio/

## How it is built

- The whole site is a **single self-contained `index.html` file** — all the CSS (design) and JavaScript (animation) are written inside that one file. No separate files, no build tools.
- **Theme:** black & red cinematic style with a film-grain effect.
- **Swarm build intro:** on load, a crew of small red cursor "agents" builds the page live in front of you — dragging boxes with live size readouts and typing text letter by letter. First the hero (first page) builds on its own; after that, the rest of the design builds **in proportion to your manual scrolling** — scroll fast and it builds fast, stop scrolling and the build freezes exactly where it is.
- **Sections:** Hero ("I am AYAN ALI" with the giant PORTFOLIO title), About, Journey, Skills, and Let's Talk (contact links: GitHub, Instagram, AWS Builder Center).
- **Extras:** typing roles animation (Polytechnic Student / AWS Cloud Learner / Cybersecurity Enthusiast), a Motion on/off toggle, a reading-progress bar, and a "Watch agents build it" replay button in the footer.
- **Hosting:** GitHub Pages, from the `main` branch root of this repo.
