About Me

A student on a mission — learning cloud, building for the web, and staying consistent every day.

I'm Ayan Ali, a Polytechnic student learning cloud computing with AWS. I believe skills are built the same way streaks are — one day at a time, without missing.

On the AWS Builder Center community, I keep a daily visit, like and comment streak going, and I share what I learn along the way by writing and building in public.

I'm also pursuing a WAPT course — Web Application Penetration Testing. Cybersecurity is a genuine interest of mine, and I'm learning how web applications are tested for weaknesses so they can be made stronger.

When I'm not studying, I'm creating websites with HTML, CSS and JavaScript and publishing them on GitHub — learning by shipping, not just by reading.
